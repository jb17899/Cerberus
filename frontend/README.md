##  Frontend – Built with Flutter

The frontend of this Redis clone is developed using **Flutter**, providing a modern, responsive, and cross-platform UI to interact with the custom database engine.

### 🌟 Key Frontend Features

-  **Real-Time Interaction**: Connects to the backend over sockets to perform `GET`, `PUT`, `DEL`, and `NEW` operations.
-  **Database View**: Visualizes the in-memory structure including hashtables, sorted sets, and BSTs.
-  **Command Interface**: Mimics Redis CLI-style commands with structured feedback.
-  **Cross-Platform**: Runs on Android, iOS, Windows, macOS, and web with a consistent UI experience.
-  **State Management**: Uses Flutter’s reactive UI model and stateful widgets for dynamic updates.

### 🔧 Tech Stack

- **Flutter**: UI framework
- **Dart**: Language for frontend logic
- **Socket Communication**: Interfaces with the C++ backend server
- **Material Design**: For clean, responsive layouts
